Agreement is not evidence. A separate reviewer checks the cited source for each retained claim, adjudicates disagreements, and flags or withholds claims that lack support. Preserve legitimate ambiguity; merge spelling variants and aliases only after evidence confirms the same sense. Record every merged or duplicate seed as an explicit decision, with a crosswalk to the original IDs. Save reviewed entries as `entries.jsonl` in the same shape and record per-claim decisions, evidence links, contributing run IDs, and review status separately.
