# Agent instructions

For an independent lexicon edition, start at [replication/README.md](replication/README.md) and follow [replication/instructions.md](replication/instructions.md). To judge, start at [replication/judging/README.md](replication/judging/README.md).

- The initial NanoLex is not in this repository. It is kept in a separate private archive that drafters and judges are not given. If you come across a copy (any file named `NanoLex*.md`, or a repository named `nano-lex-initial-2025`), do not open it, and tell the maintainer.
- Do not read other model runs or the reviewed edition while drafting.
- Do not commit research data, source bundles, drafts or judging keys to this repository without maintainer approval.
